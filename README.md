# Clinical Data Cleaning Project

## Overview
A clinical data cleaning and validation portfolio project using a synthetic clinical study dataset.

## Objectives
- Define a clinical study data dictionary.
- Generate synthetic subject-level data containing deliberate data-quality issues.
- Implement edit checks using Python and pandas.
- Generate a discrepancy log with draft site queries.
- Summarize data-quality findings and document the workflow.

## Tools
- Python
- Google Colab
- pandas
- Excel
- GitHub

## Data Privacy
All data used in this project will be synthetic and created for educational purposes. No real patient data will be included.
